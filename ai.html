/03 — AI TRANSPARENCY

Yes, we use AI.
No, it isn't the CEO.

We are web developers with limited time. We use AI to help make software. This is a disclosure, not a confession.

THE IMPORTANT BIT

All released code is human-reviewed.

AI-generated work is checked before release. Responsibility for what ships remains with the studio, not the model.

To the AI critics

Using a tool does not automatically mean abandoning technical judgment. We use AI to assist with implementation, debugging, documentation and repetitive work. The goal is useful software, not a competitive typing championship.

To the AI evangelists

No, a prompt is not a substitute for understanding a codebase. A confident answer can still be spectacularly wrong. Generated code needs review, testing appropriate to the change, and maintenance. The word “agentic” does not magically fix a broken function.

What human review means

We check generated work for intended behavior, obvious errors and relevant security and privacy concerns before publishing. Review is not a guarantee of perfection, and bugs can still happen. If you find one, tell us.

AI in development versus AI in products

Using AI to help write software does not inherently mean that the software sends your data to an AI service. Product-specific behavior should be assessed separately.

Accountability

We own the decisions, the code we publish and the responsibility to address problems. Blaming a chatbot is not a maintenance plan.
